# llm-cost-guard Pro (paid)

The core library is free forever under Apache-2.0. **Pro** is a thin layer on
top for teams that need scoping, attribution, and dashboards.

| Feature | Core (free) | Pro |
|---|---|---|
| Per-call cost tracking | included | included |
| Single global budget | included | included |
| Per-user / per-key budgets | - | included |
| Cost attribution tags | - | included |
| Rollup reports (by day/tenant/model) | - | included |
| Slack / Teams / PagerDuty alerts | - | included |
| Prometheus / OpenTelemetry export | - | included |
| Web dashboard | - | included |
| Unlimited seats | - | flat license |

## Licensing

Pro is distributed as a separate private package (`llm-cost-guard-pro`).
Contact us for a quote or purchase a seat from the repository owner.

## Fair use
